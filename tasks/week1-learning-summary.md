## 核心收获

### AI×Web3 四层架构
```
🤖 AI          → 建议和编排
👛 钱包        → 授权确认
📜 智能合约    → 可验证执行
📊 监控/索引   → 记录结果
```

### 关键认识
1. **Agent 不只是聊天** — 从"回答问题"到"执行流程"，需要工具调用、上下文管理和权限控制
2. **钱包是 Agent 的签名入口** — Session Key、限额、时间范围是 Agent Wallet 的关键设计点
3. **合约是可验证的执行层** — 链上规则确保 Agent 的行为可审计、不可篡改
4. **监控是信任的基础** — 没有日志和索引，Agent 的行为就无法追踪和验证

### Hackathon 方向
Agent Payments / AI-native Wallet — 用智能账户表达 Agent 权限，用链上合约完成自动化结算
