## 笔记摘要

**密码学核心概念：**
- 哈希函数：SHA-256、Keccak-256，单向性、抗碰撞
- 非对称加密：椭圆曲线（secp256k1, ed25519），公私钥对生成
- 数字签名：ECDSA, EdDSA, 签名/验签流程
- 与 AI×Web3 的连接：Agent 的签名授权、链上验证、Session Key 管理都依赖密码学原语

**AI×Web3 四层架构（从密码学到智能合约的链路）：**
- **AI 做建议和编排** → 理解用户意图、拆解任务、组织工具调用
- **钱包做授权确认** → 身份验证、签名授权、Session Key 管理
- **合约做可验证执行** → 链上规则部署、状态更新、不可篡改
- **监控记录结果** → 事件监听、链上索引、日志审计
