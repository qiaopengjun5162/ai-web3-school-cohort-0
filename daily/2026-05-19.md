### Handbook: AI 基础
- **RAG（检索增强生成）**：解决 LLM 知识截止和幻觉问题，核心是检索 + 生成双阶段
  - 分块策略、向量嵌入、相似度检索
  - Web3 场景：链上数据索引 + 区块信息检索
- **Agent**：LLM + Tool Use + 记忆 + 规划 = 自主代理
  - 工具调用是 Agent 的核心能力：模型的输出决定调什么工具，工具返回结果再交给模型推理
  - ReAct 模式：思考 → 行动 → 观察 → 循环
- **Frameworks**：Agent 开发框架概览
  - 框架抽象了 LLM 调用、工具注册、记忆管理
  - 对比不同框架的设计哲学
