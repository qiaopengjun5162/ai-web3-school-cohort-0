**Notes:**

**LLM (大语言模型) 要点：**
- LLM 是概率模型，不是知识库 — 输出基于训练数据中的模式，不是"理解"
- Token 是基本单位，Context Window 限制了模型一次能"看"多少
- 知道什么时候该信 LLM、什么时候必须验证

**Prompt (提示词) 要点：**
- 好的 Prompt = 明确的任务目标 + 输出格式 + 边界条件
- 结构化 Prompt 比自然语言更稳定
- 在 AI × Web3 场景，Prompt 还可能成为攻击面（Prompt Injection）

**Context (上下文) 要点：**
- 模型一次能看到的全部信息 = System Prompt + 对话历史 + 检索结果
- 信息有过期时间 — 链上数据尤其明显
- 可信度分层：工具返回的 > 模型生成的 > 用户提供的
