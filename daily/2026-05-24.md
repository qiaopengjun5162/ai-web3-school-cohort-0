## 笔记摘要

- Network: 理解了区块链网络的层次结构，L1 共识层 vs L2 执行层的关系，RPC 作为链上状态入口的核心作用
- Account Abstraction: AA 的核心价值在于权限表达的灵活性——不再是 EOA 的全有全无，而是可以细粒度指定额度、时间、操作类型和撤销条件。这对 Agent Wallet 场景至关重要：Agent 不需要持有私钥，而是通过 Session Key 在 Policy 约束下执行操作
- DeFi: AMM 用 x*y=k 常数积模型解决了订单簿流动性问题，借贷协议用超额抵押管理风险，流动性挖矿是激励层的典型设计
- Oracle: AI 给出结果 → 系统记录来源和置信度 → 高风险场景引入 human-in-the-loop、挑战期、多人验证或经济惩罚。这套从预言机到 AI 输出的信任链路是 Agent 可信执行的关键
- Indexing: 链上数据索引就是把零散的事件和交易整理成 queryable 的结构化数据，对 Agent 来说就是链上状态的"知识库"入口
- Security: 模型可以建议 → 工具返回事实 → policy 限制权限 → simulation 预演结果 → human check 确认高风险动作 → monitoring 记录执行后果。一条完整的 AI×Web3 安全流水线，也是 Agent Payment 系统的安全骨架
